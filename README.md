# プロフィール／自己紹介サイト

Webエンジニア・蛯名哲也の自己紹介、スキル、活動内容を紹介する
1ページのプロフィールサイトです。

実案件を想定した制作課題として、情報設計から実装・公開・性能確認まで取り組みます。

## 公開URL

未公開。Vercelへのデプロイ後に追記します。

## スクリーンショット

完成後にPC・スマートフォンの画面を追加します。

## 想定する閲覧者と目的

- 企業の採用担当者・開発担当者
- Webシステム開発を依頼する事業者

開発者の得意分野、仕事への姿勢、活動内容を短時間で把握できることを目指します。

## 主な機能

- 自己紹介・スキル・経歴の表示
- ページ内ナビゲーション
- 画面幅に応じたレイアウト
- 日本語のページタイトル・説明文
- キーボード操作時のフォーカス表示と本文へのスキップリンク

## 使用技術

- Next.js 16 / App Router
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint
- 公開先：Vercel（予定）

正確な依存関係はpackage.jsonとpackage-lock.jsonを参照してください。

## ローカルでの起動

Node.jsのバージョンは.node-versionに記録しています。

fnmを使っている場合：

```bash
fnm install
fnm use
npm ci
npm run dev
```

ブラウザで http://localhost:3000 を開きます。
ポートが使用中の場合は、ターミナルに表示されたURLを使用します。

## 品質確認

```bash
npm run lint
npm run build
```

本番用ビルドをローカルで確認する場合：

```bash
npm run start
```

## ディレクトリ構成

- src/app/page.tsx：トップページの内容
- src/app/layout.tsx：共通レイアウト・メタデータ
- src/app/globals.css：Tailwindの読み込みと共通スタイル
- public/：画像などの公開ファイル
- docs/learning-notes.md：仕組みと学習内容

## 設計上の工夫

- 見出し、紹介文、スキル、経歴の順で情報を整理
- 繰り返すカードは配列から生成し、更新箇所を集約
- 小さい画面では1列、広い画面では複数列で表示
- クライアント側の状態管理やイベント処理を追加せず、
  App RouterのServer Componentとして実装
- 外部フォントや大きな画像を使わず、転送量を抑える
